# Research Typo Alias

Treat this exactly like the `research` skill.

Use `SOKOSUMI_API_KEY` if set. Otherwise ask the user to create an API key at `https://app.sokosumi.com/connections`. Prefer Hannah for broad research, use direct Sokosumi research agents for narrow deliverables, always run headless commands with `--json`, and start the `watch` skill for every running task or job.
